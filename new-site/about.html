这里是哪儿

LEA聊天记录大赏 是一个纯静态的存档站，用来收集、整理和展示群聊中出现过的 有趣片段、人物群像、梗与相关资源。所有内容都以 Markdown 文件的形式保存在仓库里， 由前端直接读取渲染，不依赖任何服务端。

站点由 Majesticrise 维护。如果你在自己的群里也见过类似的荒诞现场， 欢迎通过下面的方式联系我。

关于这个站的技术

  • 纯静态：原生 HTML / CSS / JavaScript（ES Module），没有框架、没有构建步骤。
  • 内容：每篇文章是 posts/ 下的一个 Markdown 文件，带 Front Matter。
  • 渲染：浏览器端用 marked.js 解析 Markdown， 可选 highlight.js 做代码高亮。
  • 索引：GitHub Actions 在推送时扫描 posts/*.md 生成 assets/data/posts.json。
  • 部署：GitHub Pages 直接托管 new-site/ 目录，不支持 Jekyll。

本站内容仅供存档与娱乐，如有冒犯请联系删除。
